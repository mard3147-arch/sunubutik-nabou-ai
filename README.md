# SunuButik & NABOU AI 🇸🇳

**SunuButik** is a local e-commerce platform designed for Senegal, empowering local merchants, delivery agents, and customers.

## 🚀 About the Project
Built for the Meta Global AI Developer Hackathon 2026, SunuButik integrates **NABOU AI**, a bilingual Wolof and French AI assistant powered by Meta Llama. 

### Key Features
- **Bilingual Assistant:** NABOU communicates fluently in Wolof and French to bridge the digital and language gap.
- **Local Commerce Support:** Guides users, clients, and merchants through product discovery, orders, and logistics.
- **MVP Architecture:** Python backend with a clean, functional web interface running locally.

## 🛠️ Tech Stack
- **AI Model:** Meta Llama API
- **Backend/Interface:** Python / Web local environment
